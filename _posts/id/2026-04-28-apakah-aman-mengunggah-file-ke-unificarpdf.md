Apa yang sebenarnya terjadi pada file Anda saat menggunakan situs web kami? Apakah ada sesuatu yang perlu Anda khawatirkan? Jawaban singkatnya adalah tidak, sama sekali tidak. Namun, kami lebih memilih memberikan informasi lengkap daripada hanya menjawab pertanyaan tersebut. Berikut alasannya.

## Tentang Kami

Aplikasi kami dibuat dengan satu tujuan utama: membuat [pengeditan PDF](/id/upload/) menjadi sederhana dan mudah diakses. Pengguna kami termasuk sekretaris, pelajar, pengacara, guru, dan bahkan pemilik usaha kecil. Setiap orang yang menggunakan layanan kami mendapatkan perhatian dan rasa hormat dari kami.

## File Anda Otomatis Terlindungi Setelah Diunggah

Saat Anda memilih file, file tersebut dikirim melalui koneksi HTTPS yang aman, yang menggunakan standar keamanan yang sama seperti yang digunakan oleh sistem perbankan online dan jaringan layanan kesehatan. Tidak ada pihak yang dapat menyadap, mengakses, atau membaca informasi Anda selama proses pengiriman.

Kami menggunakan protokol HTTPS karena protokol ini memberikan perlindungan keamanan dan mencegah pihak lain yang memantau jaringan membaca informasi yang dikirimkan.

## Tidak Ada Orang di UniFicarPDF yang Dapat Melihat File Anda

Baik pengembang kami, tim dukungan, maupun staf lainnya tidak memiliki akses ke file Anda. Perangkat lunak kami memproses dokumen secara otomatis dan mengembalikan hasilnya langsung kepada Anda.

## Berapa Lama File Saya Disimpan?

Jawabannya sederhana: hanya sampai proses PDF selesai. Anda memiliki waktu yang cukup untuk mengunduh file hasil pemrosesan sebelum file tersebut dihapus secara permanen dari server kami. Tidak ada salinan yang dibuat, dan kami tidak menggandakan dokumen Anda. Setelah masa penyimpanan berakhir, file akan dihapus secara permanen.

Anda juga dapat memilih untuk menghapus file sendiri segera setelah proses selesai jika Anda menginginkannya.

*Ini berarti semua hal yang berkaitan dengan file Anda hanya terjadi di server selama proses pemrosesan dan akan dihapus setelahnya.*
